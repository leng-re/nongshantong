# 农膳通 · 农产品健康电商平台前端框架

基于知识库《农膳通内容框架》生成的 HTML + CSS 静态前端框架，纯手写、零依赖。

## 目录结构

```
nongshantong/
├── index.html          # 首页
├── login.html          # 登录 / 注册页
├── ai-assistant.html   # AI 健康助手（饮食方案 / 营养查询 / AI 对话）
├── cart.html           # 购物车 / 结算页
├── css/
│   └── style.css       # 全局样式（设计系统 + 通用组件 + 各页面布局）
└── README.md
```

## 页面与模块对应关系

| 页面 | 文件 | 主要模块 |
|------|------|----------|
| 首页 | `index.html` | 顶部导航 · Hero 主视觉 · 5 大商品分类 · AI 健康助手横幅 · 热门推荐 · 产地溯源 · 用户评价 · 页脚 |
| 登录/注册 | `login.html` | 左侧品牌宣传区（三大卖点）· 右侧登录/注册 Tab 切换 · 账号密码 · 第三方登录 |
| AI 健康助手 | `ai-assistant.html` | 共用侧边栏 · 健康饮食方案（基础信息+偏好标签+目标卡片）· 食材营养查询（上传区）· AI 营养师对话 |
| 购物车/结算 | `cart.html` | 左侧商品列表（数量增减/删除）· 智能推荐 · 右侧订单摘要 · 优惠码 · 健康提示框 |

## 如何预览

直接用浏览器打开 `index.html` 即可。各页面顶部导航相互联通，可完整走通「浏览 → 咨询 → 加购 → 结算」闭环。

## 设计系统（css/style.css）

- **主色**：有机绿 `--green-600 #3d9a45`（健康、可信）
- **辅助色**：低卡暖橙 `--orange-500 #ff7a33`（CTA、价格、热量强调）
- **组件库**：按钮 `.btn`、标签 `.tag`、卡片 `.card`、表单 `.input/.select`、徽章 `.chip`、上传区 `.dropzone`、对话框 `.chat` 等
- **变量驱动**：颜色 / 圆角 / 阴影 / 过渡均以 CSS 变量定义于 `:root`，改一处即可全局换肤
- **响应式**：内置 1080px / 760px / 480px 三档断点，移动端自动折叠导航与网格

## 交互说明

- 登录/注册的 Tab 切换、AI 助手侧边栏锚点均使用 **纯 CSS/HTML** 实现，无 JavaScript 依赖。
- 页面中的商品图、头像、产地图片使用统一渐变占位块（`.ph`），接入真实图片时替换对应元素即可。
